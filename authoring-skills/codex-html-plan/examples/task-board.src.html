チーム作業ボードの担当絞り込み

目的・依頼原文チームの作業一覧で、自分の担当だけを素早く見たい。

全体像

チームの作業を確認する利用者が、「すべて」と「自分の担当」を切り替える。既存の一覧取得APIを使い、表示時に担当IDで絞り込む。

利用フロー: ボードを開く → 自分の担当を選ぶ → 担当カードを確認 → すべてに戻す。

主要状態: 全件、担当あり、担当なし、読込中、取得失敗。第1段階で表示と切替、第2段階で受入確認を行う。対象はボード画面と一覧状態。認証、API契約、通知、保存済みフィルタは対象外。

仕様正本は TASK-42 / 仕様v2。承認根拠は正本だけに記録する。このHTMLは未承認 / pending。

確定仕様

利用者は全件と自分の担当を切り替えられる。

表示だけを切り替える。

担当IDと利用者IDの一致でカードを絞り込む。

担当なし・読込中・失敗でも次の操作が分かる。

フィルタを戻すと取得済みの全件を表示する。

画面状態と利用者IDを既存の一覧に渡す。

認証、API契約、通知とフィルタの永続保存は対象外。

  • 担当の変更は既存の編集画面を使う。
  • 新しいAPIや認証方式は導入しない。

番号付き受入条件

  1. AC1: 全件/担当の切替で該当カードを表示する。関連: 仕様1。
  2. AC2: 担当なし、読込、失敗の各画面を表示し、復帰操作を示す。関連: 仕様2。
  3. AC3: 全件への復帰で不要な再取得を行わない。関連: 仕様3。
  4. AC4: 390px幅で表示と操作が可能。関連: 仕様1、仕様2。
