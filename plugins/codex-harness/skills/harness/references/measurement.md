# 計測

設定で有効な場合だけ、取得できる開始・終了の情報を記録します。比較実験は、明示的に依頼されたときだけ実行します。通常の依頼から、高コストなベンチマークを始めません。

条件（baseline/harness）、タスクIDとrun ID、開始と終了、所要時間、担当モデル、修正回数、完了と欠陥を記録します。取得できれば、利用枠の前後の値とリセット窓も記録します。未取得はnullとします。計測値を推測したり、トークン数から利用枠を換算したりしません。

アカウント共通の利用量の差分は、厳密なタスク原価ではありません。他の実行が重なった場合や、リセット窓をまたぐ場合は、比較無効とします。親子すべての作業を含めます。

明示的なベンチマークでは、小変更・機能追加・不具合修正のそれぞれについて、通常実行とハーネス実行を同一の開始状態から3回ずつ行います。品質が下がらず、利用枠消費の中央値が下がった場合だけ、削減効果を報告します。粒度が足りない場合や値が足りない場合は、未確認と記載します。
