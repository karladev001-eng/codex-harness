# Webを参照した回答の出典

activeでWebを根拠に回答するときに適用します。検索自体は要求しません。上位指示とユーザー指示、既存の規則を優先します。

- 主要な根拠にあたる主張の近くに、`[説明的な資料名](<実際の外部ページの絶対URL>)` を付けます。一次資料を優先し、主張を支える実際のページへ直接リンクする。検索結果ページ・内部ID・推測/捏造URLは禁止です。
- 論文では、確認済みのタイトル、著者（多数なら筆頭著者ら）、年、DOIまたは出版社・arXiv等の直接リンクを示します。未確認書誌は未確認とし、捏造しない。判断に影響する閲覧範囲（抄録のみ、本文の一部など）と推測を明示し、未読の本文を読んだとしない。
- 完了前に、主張とリンクの対応、主要な出典の識別、書誌と閲覧範囲を確認し、出典を回答内に示します。既存の調査タスクがあれば、確認範囲と未確認事項をパケットに更新します（persistence OFFなら会話内だけ）。この規則だけで記録ファイルを作らない。

純Web調査は通常の回答に戻り、コード調整・実装委譲・worktree・統合を要求しない。大規模探索を明示的に委譲する場合のみ、[論文探索/資料確認の役割手順](../roles.md)を使います。コードや制作を伴う場合は、それぞれの手順も適用します。
