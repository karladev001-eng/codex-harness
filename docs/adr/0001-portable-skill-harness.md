# ADR 0001: 移植可能なスキルと小さな実行補助

状態: 採用、2026-09-26にTypeScript/Nodeへ改訂

## 背景

Codexアプリ内でメインの文脈を小さく保ち、軽い実装担当と独立レビューを使いたい。複数PCへの導入と全OFF時の通常動作が必要。独立作業は並列化する。

## 決定

オーケストレーションはスキルと担当別指示で記述する。2026-09-21時点では、設定・記録・worktree・導入をPython標準ライブラリによる補助ツールで扱った。配布用のCodexプラグイン構造を保持しつつ、v1のセットアップは自己完結した単体スキルを登録する。マーケットプレイスや外部APIへの依存を避け、導入手順を他PCでも再現可能にする。

### 2026-09-26: TypeScript/Nodeへの改訂

補助ツールはTypeScriptからコンパイルしたJavaScriptへ移行する。配布物はnpm tarballにCLI、自己完結したskill、Codexプラグイン、authoring skillを含め、Node.jsとnpmだけで実行・導入できるようにする。実行時の外部依存は持たず、旧schema-1のPython導入はPythonを実行せずに移行する。現在のインストール、配布、必要環境は[README](../../README.md)を正とする。

メインは仕様・判断・調整を行い、実装と統合は委譲する。並列実装では個別worktreeを使い、依存関係に沿って統合する。子の同時稼働上限は３を既定とする。子は再委譲しない。

## 影響

実行順序とモデル選択はCodexの指示遵守・ホスト機能に依存する。補助ツールのテスト合格は、実際のエージェントの挙動や利用枠節約を保証しない。実運用の受入検証を別に記録する。

単体スキル導入はプラグイン一覧へのインストールとは別経路であり、READMEと診断で区別する。将来マーケットプレイス配布を追加しても、仕様・役割・設定を再利用できる。
