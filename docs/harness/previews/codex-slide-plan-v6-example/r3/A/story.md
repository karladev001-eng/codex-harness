# 平均時間の差を読み、実運用で確かめる

Deck: batch-comparison / revision: r3

目的: 現行と改善案の平均処理時間を共有し、実運用で確かめる条件を整理する

相手: 開発者と非技術部門の合同会議

要旨: 演習の平均差15秒を読み、実測条件を決める

期待: 平均時間の差を理解し、仮想値と実運用の効果を区別できる

## 1. S01 — 同じPC・各3回の演習用仮想値で比較する

役割: 比較する目的と前提を共有する

同じPC・各3回の演習用仮想値で比較する

- バッチ処理はデータをまとめて処理すること
- 現行と改善案の時間を比較する
- 今回は演習用の仮想値

つなぎ: 条件をそろえて、次に平均時間を見ます。

出典: brief, measurements

## 2. S02 — 演習の平均時間は15秒短縮

役割: 平均の比較結果を示す

演習の平均時間は15秒短縮

- 現行の平均は40秒
- 改善案の平均は25秒
- 現行比37.5%短い

つなぎ: この演習の差が示せる範囲を確認します。

出典: measurements, summary
