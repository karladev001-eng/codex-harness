# 比較の数字と条件を一緒に読む

Deck: comparison-demo / revision: r1

目的: 処理手順の比較を前提と条件付きで説明する

相手: ETLを知らない企画担当。実測前に比較の見方を知りたい

要旨: 数字と条件をセットで読む

期待: 仮値から実測の効果を決めず確認条件を選べる

## 1. S01 — 数字と条件を一緒に読む

役割: 今日の判断を示す

仮値を使って比較の見方を共有する

- 今日は比較の読み方を確認する
- 実測結果ではない

つなぎ: まず比較に必要な条件を整理します。

出典: brief

## 2. S02 — 比較条件を揃えて読む

役割: 比較の前提を渡す

同じ入力・対象範囲で手順を比べる

- 入力、手順、条件の順に読む
- ETLの説明を補う

つなぎ: ここから本番導入の判断へ進みます。

出典: brief, concept-flow

## 3. S03 — 仮値では一括処理の時間が短い

役割: 結果を条件付きで読む

18分と9分の比較例。実測ではない

- 手動18分、一括9分という仮値
- 条件は出典から確認

つなぎ: 例の見方を次の確認手順にまとめます。

出典: illustrative-data, comparison-derived

## 4. S04 — 実測の確認事項を決める

役割: 次の行動に結びつける

入力・範囲・単位を揃えて実測を記録する

- 仮値は意思決定の根拠にしない
- 実測する条件を揃える

つなぎ: 以上です。どの条件を実測で確認するか相談します。

出典: concept-flow

未解決: 実測の担当と期間は本資料の対象外
