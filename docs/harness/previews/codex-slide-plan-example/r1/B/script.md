# 比較の数字と条件を一緒に読む

Deck: comparison-demo / revision: r1

## 1. S01 — 数字と条件を一緒に読む

### S01-P01

今日は処理手順を比べるときに何を一緒に確認するかを整理します。説明には仮の数字を使います。実測結果の報告ではありません。

出典: brief

つなぎ: まず比較に必要な条件を整理します。

## 2. S02 — 比較条件を揃えて読む

### S02-P01

ETLで入力を揃えたあと手順を比べます。同じ入力を使う想定で、待ち時間は比較に含めません。

出典: brief

つなぎ: ここから本番導入の判断へ進みます。

## 3. S03 — 仮値では一括処理の時間が短い

### S03-P01

こちらは説明用の仮値です。手動を18分、一括を9分としています。この差は実測の短縮効果ではありません。入力、測定範囲、待ち時間の扱いを確認するという見方を共有するための例です。

出典: illustrative-data

つなぎ: 例の見方を次の確認手順にまとめます。

## 4. S04 — 実測の確認事項を決める

### S04-P01

要点は数字と条件をセットで読むことです。実測する場合は入力、測定範囲、単位を揃えて記録します。この仮値から本番導入の効果を決めることはできません。次は実測で確認する条件を決めましょう。
