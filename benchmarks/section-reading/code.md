# コード修正の依頼

ローカルのCLIツールで、`--limit 0`を指定しても既定の20件が返ってくる不具合を修正してください。期待する動作は0件を返すことです。上限未指定は20件、正の整数は指定件数、負数と整数以外は既存の入力エラーにしてください。関連する回帰確認を行い、変更の独立レビューまで進めてください。

変更はCLIの引数解釈と該当テストに限ります。UIや公開仕様、外部サービスは関係しません。既存の未コミット変更を保持してください。先に親から提示された仕様v1（上記の入力・受入条件、UI非該当）を確認済みです。この仕様版・範囲の実装開始を承認します。公開・pushは求めていません。外部のAIへの相談は今回は明示的にOFFとします。

実際の修正に着手する前に、準備から実装・独立レビュー・統合・結果報告までの各工程で、親としてどの運用手順を適用するかを確認してください。
