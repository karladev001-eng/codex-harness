# 計測

設定で有効な場合だけ、取得可能な開始・終了情報を記録する。比較実験は明示的な依頼時だけ実行し、通常の依頼から高コストなベンチマークを始めない。

条件（baseline/harness）、タスク・run ID、開始終了、所要時間、担当モデル、修正回数、完了・欠陥、取得できれば利用枠の前後値とリセット窓を記録する。未取得はnull。計測値を推測したり、トークン数から利用枠を換算したりしない。

アカウント共通の利用量差分は厳密なタスク原価ではない。他の実行が重なった場合、リセット窓をまたぐ場合は比較無効とする。親子すべての作業を含める。

明示的ベンチマークは小変更・機能追加・不具合修正それぞれ、通常実行とハーネス実行を同一開始状態から3回ずつ。品質が下がらず利用枠消費の中央値が下がった場合のみ削減効果を報告する。粒度不足・値不足なら未確認と記載する。
