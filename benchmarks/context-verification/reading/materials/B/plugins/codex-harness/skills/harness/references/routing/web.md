# Webを参照した回答の出典

activeでWebを根拠に回答するときに適用する。検索自体は要求しない。上位/ユーザー指示と既存規則を優先する。

- 主要根拠の主張の近くに `[説明的な資料名](<実際の外部ページの絶対URL>)` を付ける。一次資料を優先し、主張を支える実際のページへ直接リンクする。検索結果ページ・内部ID・推測/捏造URLは禁止。
- 論文は確認済みタイトル・著者（多数なら筆頭著者ら）・年・DOIまたは出版社/arXiv等の直接リンクを示す。未確認書誌は未確認とし捏造しない。判断に影響する閲覧範囲（抄録のみ/本文の一部等）と推測を明示し、未読の本文を読んだとしない。
- 完了前に主張/リンクの対応、主要出典の識別、書誌/閲覧範囲を確認し、出典を回答内に示す。既存調査タスクは確認範囲・未確認事項をパケットに更新（persistence OFFは会話内のみ）。この規則だけで記録ファイルを作らない。

純Web調査は通常回答へ戻り、コード調整・実装委譲・worktree・統合を要求しない。大規模探索を明示委譲する場合のみ[論文探索/資料確認の役割手順](../roles.md)を使う。コード/制作を伴えば各手順も適用する。
