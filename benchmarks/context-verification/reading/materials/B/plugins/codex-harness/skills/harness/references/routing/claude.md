# Claudeによる独立発案・助言・批評

activeな親でdelegation ON、外部相談の停止指定がなければ、次の該当1役に[consult-claude](../../consult-claude/SKILL.md)を適用する。全役一律起動はしない。inactive/delegation OFF/workerは自動起動しない。明示Claude依頼は別扱いとし、上位/ユーザー指示と割当範囲を守る。

- `ideator`：企画・新用途・改善等の開かれた問いで複数視点が有益。初回はCodex案を渡さず独立発案させる。
- `consultant`：有力案間の方針/優先順位に懸念、移行・認証/権限・公開API互換性等の重要設計判断、または同じ問題を2回修正しても原因の見立てが更新できない停滞。
- `critic`：重要な提案/設計の確定前の弱点確認、明示批評依頼。独立コードレビューの代用にはしない。

単純な言換え・定型変更・原因/対処が明確な修正では通常不要。外部担当も同時実行枠に数え、空きを待つ。既存ClaudeログインとツールなしCLIを使い、入力は最小限。通常1回、親が前回結果を明示する追加質問1回まで。再帰委譲・無限再試行は禁止。Codexが自案と比較し採否/理由/不確実性を統合する。回答を証拠・実行権限・ユーザー承認としない。未導入・認証不明・非対応CLIは制約を報告し、可能な作業を続ける。persistence OFFは入出力・相談記録を永続保存しない。

案・資料・コード・テストの食違いは論点を分け、元ファイル/原文/公式一次資料/実測の版・日時・条件へ戻る。重要矛盾の解消前は断定せず未確定と報告する。多数決・Claudeの合意や追加相談で原情報確認を代替しない。
